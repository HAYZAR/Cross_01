# Crucigrama: Vibraciones y Ondas - versión validada

Esta versión corrige el problema observado: había celdas blancas que parecían formar palabras, pero no correspondían a ninguna pista. La matriz fue validada para que todas las secuencias horizontales y verticales coincidan exactamente con las 20 claves.

## Subir a GitHub Pages
Sube al repositorio únicamente:
- index.html
- styles.css
- script.js
- config.js

## Google Sheets
El archivo `apps_script.gs` se pega en Google Sheets > Extensiones > Apps Script. Luego copia la URL de implementación y pégala en `config.js`.
